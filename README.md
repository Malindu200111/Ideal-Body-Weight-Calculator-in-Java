# Ideal-Body-Weight-Calculator-in-Java
The Ideal Body Weight Calculator is a Java-based application that uses the Devine Formula to estimate a person’s ideal weight based on height and gender. It provides the healthy weight range, identifies whether the user is underweight, healthy, or overweight, and offers simple health tips accordingly.
